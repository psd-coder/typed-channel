Three guides, in the order most people need them.

## [Messages](/guides/messages)

Define a message map, create a channel over a transport, and send and receive messages with
full type checking. This is `createTypedChannel`, the smaller of the two factories.

## [Requests](/guides/requests)

Send a request and wait for one response, answer a request on the other side, and stop a
request with a timeout or an abort signal. This is `createTypedRpcChannel`.

## [Transports](/guides/transports)

The transports that ship with the library, and how to write your own for any messaging API.
